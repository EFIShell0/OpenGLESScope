# OpenGLESScope Database 0.1.21 Full Parity, Security and Specification Audit

## Scope
This audit compares OpenGLESScope Database 0.1.20 with OpenGLESScope 0.1.24 producer output and VulkanScope Database 0.35.8 shared database behavior.

## Corrected defects
- Reports omitted Android and ABI despite current canonical reports containing the evidence.
- Android sorting referenced summary fields not returned by the Worker list endpoint.
- ABI evidence was inaccessible outside Raw report.
- Main-navigation and detail-tab scroll-into-view paths did not fully honor reduced-motion preference.
- Worker health metadata did not expose published OpenGL ES/GLSL ES/EGL provenance with the same clarity as the Vulkan database.

## Required behavior
- Structured Android release/API is authoritative.
- ABI is structured when available; otherwise exact canonical TXT header evidence is the only fallback.
- No ABI or platform inference from GPU/device names.
- Current 0.1.24 TXT identity must agree with structured GPU, driver mode, OpenGL ES and Android identity.
- Runtime extensions remain exact implementation-reported tokens.
- All shared security and responsive interaction invariants from PROJECT_RULES.md remain release gates.

## Specification baseline
- OpenGL ES 3.2
- GLSL ES 3.20
- EGL 1.5
- Khronos registry audit date: 2026-08-21
