# OpenGLESScope 2.2.18 notification and EGL evidence audit

Immutable predecessor: OpenGLESScope 2.2.17 SHA-256 `21992266509b5cd28338bb443503349f76fcdfd0c3fed840319cb5bb7de909d5`; production paths: 160.

## Observations and fixes
- Every relevant shared drawable (offline info, connected/disconnected, update available, loading and terminal collection icons) matched the VulkanScope 3.0.12 file SHA-256. Source durations, network validated transition and status overlay arrangement already matched; no icon resources or Android manifest were modified.
- GL/EGL terminal failure was incorrectly cleared after 2.2 seconds while VulkanScope preserves CollectionStatus.FAILED. Automatic dismissal now occurs only after successful CollectionStatus.COMPLETED. The Unknown/Unavailable probe path also maps to FAILED without inventing GPU support.
- EGL_VENDOR, EGL_VERSION, EGL_CLIENT_APIS and display extensions now read EGL error independently; required identity failures fail the complete report instead of treating a non-null errored value as evidence. EGL 1.2 applicability for EGL_CLIENT_APIS and pre-1.5 EGL_NO_DISPLAY/EGL_BAD_DISPLAY handling are explicit. Self-test display extension query is checked.
- No locked Khronos registry files or schema keys were changed. Existing code-level canonical-name, query coverage, EGL applicability, GL GetPName, report-contract, security and native host helper gates must pass; current external core specification index was inspected for ES 3.2 and EGL 1.5. This is not evidence of exhaustive verification against a future extension registry revision or on all hardware.
- Android build/lint/device verification remains separate from static PASS; Database 1.0.16 admission of a new producer identity needs separate deployment.

## Allowlisted production changes
- `app/src/main/java/com/efishell/openglesscope/MainActivity.kt`: Keep failed or unknown GL/EGL collection notification visible until a new collection, matching VulkanScope terminal-failure lifetime.
- `app/src/main/cpp/openglesscope.cpp`: Treat errored EGL identity strings as unavailable, distinguish EGL_BAD_DISPLAY legacy client discovery from other errors, validate mandatory identity and self-test extension query.
- `app/build.gradle.kts`: Release version 2.2.18 / 2218 without changing schema or SDK.
