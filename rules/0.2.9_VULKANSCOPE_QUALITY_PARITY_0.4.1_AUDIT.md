## Compare parity

- Compare keeps Differences only and Technical differences only and adds Common evidence only.

## Routing parity

- Canonical report route is `#reports/<64-hex-id>/Overview`.
- Canonical section routes use the same report ID plus a validated section token.
- `#reports/<64-hex-id>` defaults to Overview.
- Canonical compare route is `#compare/<64-hex-id>/<64-hex-id>`.
- Invalid IDs and unknown sections fail route validation.
