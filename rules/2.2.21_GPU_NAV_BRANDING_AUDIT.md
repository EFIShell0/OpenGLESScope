# OpenGLESScope 2.2.21 source audit

Classification: ACCESSIBILITY/UX (hero color/navigation/EGL semantics), REPORT-INTEGRITY PRESENTATION (no invented numeric Vendor ID), BUG (vendor logo inference).

- Baseline: OpenGLESScope 2.2.20 exact ZIP `a2bf1c9469bfd5bf8b6056f04be9908e89cdd8076537e8b0ff0495de985156f9`; VulkanScope 3.0.12 source as API-neutral hero/navigation reference.
- `GL_VENDOR`, `GL_RENDERER`, `EGL_VENDOR`: distinct raw runtime strings. Khronos GLES `glGetString` returns GL_VENDOR and GL_RENDERER as text, not a numeric hardware vendor ID; EGL_VENDOR is independent EGL implementation text. The source reports no unverified numeric vendor ID.
- GL_VENDOR-only vendor-artwork mapping: distinct exact-enough name boundaries, translation and software fallbacks; output is illustrative and is shared by hero and public Database cards. Model text remains raw GL_RENDERER.
- Original official EGL PNG and all logo assets retain SHA-256. Distinct EGL identity/context/pbuffer variants are composed from the existing official PNG and existing semantic icons.
- EGL is no longer a primary bottom tab but stays reachable under OpenGL ES and Overview. Display is a primary destination in both orientations; tablet/system insets, RTL and touch targets are retained.
- Native collector and reports are not changed; this release does not claim to improve upstream registry coverage, discover a new hardware vendor ID or validate physical GPUs by branding.
- Gradle assemble/lint/unit and physical-device visual parity: NOT EXECUTED in this source audit environment unless separately documented.

- Asset audit: gpu_vendor_vsi.png and gpu_vendor_vivante.png have the same SHA-256. A claimed VeriSilicon image would actually show the Vivante artwork; unknown/neutral is intentional. Anchored GL_VENDOR matching protects against `Google Inc. (Qualcomm)` false positives.
