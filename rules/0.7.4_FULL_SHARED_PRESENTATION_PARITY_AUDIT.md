# OpenGLESScope Database 0.7.4 full shared presentation parity audit

## Scope
OpenGLESScope Database 0.7.4 keeps the OpenGL ES/EGL evidence model and magenta brand identity while matching the shared interaction geometry of VulkanScope Database 0.39.8 wherever the two products expose the same UI role.

## Compare
- Report A/B selectors and Differences only, Technical differences only and Common evidence only use the compact primary picker contract.
- Section and Field search use one secondary subfilter row generated from the shared control helpers.
- Share comparison link is outside both control rows.
- Desktop control rows are bounded to 760 CSS px and do not create large unused vertical gaps.
- Responsive behavior uses two columns at tablet widths and one column at narrow phone widths.
- Evidence semantics, cross-producer warnings, Unknown / Not reported handling and canonical comparison URLs are unchanged.

## Shared presentation geometry
- Navigation spacing/icon geometry, hero heading spacing, card-grid minimum width, custom-select controls and menus, table-scroll geometry and page-button states use the shared reference dimensions.
- OpenGL ES and EGL logo presentation, magenta accent colors and API-specific table/data categories remain product-specific.
- Clear filters is hidden while no active visible filter/search exists.

## Release gates
- Browser assets are app.v074.js and site.v074.css only.
- `tools/test_ui_parity.mjs` validates the shared geometry contract.
- `tools/build_index.py` writes 0.7.4 / OpenGLESScope 0.7.2 metadata before source audit.
- Repository repair removes transient dependency/cache/build directories and forbidden root documentation files automatically.
- D1 schema and stored reports are unchanged; no migration is required.
