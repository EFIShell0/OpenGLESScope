# OpenGLESScope 2.2.22 evidence, security and provenance audit

- Base archive: OpenGLESScope 2.2.21; SHA-256 `e7db9cdbc1b6540372f4c14d55ccc7781aedfdd254dde8a6eb7a0820db902b64`. All 160 production files are hashed; only MainActivity.kt and app/build.gradle.kts may differ.
- ACCESSIBILITY/UX: removed uncontained `CapabilityKeyValueStatic` layout. Adopted the reference VulkanScope 3.0.12 `ExpressiveEvidenceRow` surface for all capability rows, including hero `EGL_VENDOR`. Normal and detail row geometry, dynamic two-column/stacked conditions, TV focus and long-hold scale/glow are locked by tests.
- EVIDENCE: EGL_VENDOR remains an independent EGL driver implementation string; no hardware vendor ID is manufactured and renderer name does not establish numeric identity. Raw runtime strings and unavailable evidence retain their original meaning.
- QUERY/REPORT: Native GL/EGL source, canonical gl.xml/egl.xml, generator artifacts, schema 5 and submission schema 2 unchanged; existing registry/census/legality/report gates are rerun. This release makes no unverified claim of new upstream extension support.
- MEMORY/SECURITY/PERFORMANCE: 8 MiB probe publication, explicit client upload, fixed HTTPS origin, bounded file operations, hard process timeout, native resource ownership, compressed history bounds, UI visible-item limits and binary-search extension membership remain unchanged under SHA-256 lock. Source-level tests alone do not prove leak-freedom or on-device performance equivalence.
- Separate gate: actual Android build/lint/unit, physical driver query comparison, LeakCanary, ASan/HWASan and prolonged heap/CPU profiling are NOT EXECUTED unless an external run is recorded.
