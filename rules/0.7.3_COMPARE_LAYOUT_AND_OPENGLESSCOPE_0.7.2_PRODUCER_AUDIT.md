# OpenGLESScope Database 0.7.3 Compare-layout and producer-parity audit

## Trigger
The Compare page placed Section, Field search and three checkbox toggles inside one generic `.compare-picker` form group. Generic label/input CSS then applied column layout and text-input sizing to the checkbox controls, producing tall vertical cards and a broken visual hierarchy.

## Correction
The control structure now matches the shared VulkanScope pattern: report selectors plus compact dedicated toggles in the primary picker; Section and Field search in `#compareFilters`; sharing outside the picker. Dedicated Compare CSS explicitly isolates hidden checkbox inputs from generic form-control rules and defines compact desktop and responsive mobile layouts.

## Producer compatibility
OpenGLESScope 0.7.2 / 702 is the current producer and retains schema 2 / technicalReport 2 semantics. No D1 migration or report rewrite is required.
