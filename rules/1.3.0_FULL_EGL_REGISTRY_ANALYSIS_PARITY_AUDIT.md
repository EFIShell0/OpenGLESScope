# OpenGLESScope 1.3.0 full EGL registry and VulkanScope-method parity audit

## Release identity
- OpenGLESScope 1.3.0 / versionCode 1300.
- Immutable predecessor: OpenGLESScope 1.2.1.
- Submission schema remains 2; technicalReport advances to schema 4 because EGL capability-query evidence is now transported end-to-end.

## Registry/specification boundary
- Both Khronos `gl.xml` and `egl.xml` are release-locked by SHA-256 in source verification and CMake.
- The offline Encyclopedia is deterministically generated from those two snapshots and keeps registry/reference metadata separate from runtime support.
- EGL 1.0–1.5 core, registered commands, enums, types and all registered extensions are catalogued. Runtime extension enumeration is evidence; a registry entry alone is never support evidence.
- Direct EGL capability queries execute only when the corresponding core version/extension/object prerequisites are present. Object-creation, platform-only, window-surface-only and action APIs without a safe collector-side query remain reference/runtime-enumeration evidence rather than fabricated capabilities.

## EGL runtime expansion
- EGL context/runtime attributes retain exact Available / Unavailable / Not applicable evidence.
- EGL device query/enumeration, query-name/device-type evidence and fixed-rate surface-compression-rate discovery are bounded and entry-point checked.
- Persistent device UUID values and raw native handles are intentionally not exported.
- Window-only buffer-age evidence is explicitly Not applicable to the isolated pbuffer collector.

## Transferable VulkanScope workspace parity
Where an OpenGL ES/EGL equivalent exists, the release includes an offline Encyclopedia, local Compare, fixed-origin Database Compare, Khronos requirements, bounded custom Minimum profiles, runtime/query Graph, Presentation evidence, searchable Raw technicalReport tree, app-private compressed Session History, heuristic Quality evidence, Watched evidence, canonical Share/permalink and isolated Tests. Vulkan-only pNext, Vulkan Profiles, Vulkan Video, Vulkan WSI structure chains and Turnip/AdrenoTools switching are not synthesized.

## Safety and release gates
- Strict report-schema validation includes `eglCapabilities` and rejects structural/type regressions.
- Database Compare accepts only a 64-lowercase-hex report id, uses the fixed HTTPS origin, disables redirects and bounds the response to 2 MiB.
- Session history is app-private, maximum 8 records, maximum 8 MiB uncompressed and 4 MiB compressed per record.
- Negative mutation tests cover both OpenGL and EGL registry/query paths.
- Deterministic package, exact `files.txt`, clean-extract full-gate rerun and byte-for-byte source/package equality remain release requirements.
