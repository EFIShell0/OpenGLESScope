# OpenGLESScope Database 0.1.7 audit

The 0.1.7 release was audited against the current OpenGLESScope 0.1.17 submission shape and the established database quality floor.

The compatibility audit verified application/package identity, producer version metadata, complete OpenGL ES and EGL extension sets, implementation limits, format enumerations, shader precision, query diagnostics, the full emitted EGL configuration attribute set, Android display/HDR evidence and canonical TXT retention.

Worker validation was tightened so nested EGL/display/config fields cannot pass only by being present. Runtime extension counts and duplicated structured extension lists must agree with their top-level runtime evidence.

Frontend parity work adds bounded JSON reads, timeout behavior, active navigation containment, overflow affordances, Display/HDR ordering, producer-version visibility, semantic state coverage and a structured fatal-error/retry surface. Coverage color is confined to progress fills unless a state is uniquely dominant.

- Frontend canonical TXT compatibility fallback is retained for older stored reports when structured normalization is unavailable.
