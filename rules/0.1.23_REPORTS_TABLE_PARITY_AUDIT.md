# OpenGLESScope Database 0.1.23 Reports Table Parity Audit

## Reference

VulkanScope Database 0.35.8 Reports presentation and the supplied VulkanScope/OpenGLESScope header captures were used as the visual reference.

## Verified changes

- Reports column label: GPU → Device.
- Complete OpenGL ES version value remains report-backed and is rendered in a single-line version chip.
- EGL initialized/runtime version remains report-backed and is rendered in a single-line version chip.
- Reports header color, size and weight match the VulkanScope reference.
- Report ID uses matching monospace size and normal weight.
- Existing horizontal table scroller remains authoritative for overflow.

## Non-regression constraints

- No capability inference or fabricated Unsupported state.
- No report-schema or D1 migration.
- No change to complete-report gating.
- No remote frontend dependency.
- No source-code comments added to active JavaScript or CSS.
