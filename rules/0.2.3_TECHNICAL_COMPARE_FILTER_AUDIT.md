# OpenGLESScope Database 0.2.3 technical Compare audit

## Scope
Verify Compare can suppress producer/report-generation metadata without hiding OpenGL ES, EGL, Android or Display/HDR technical evidence.

## Required behavior
- Differences only and Technical differences only use the same compare-toggle component.
- Technical differences only defaults on.
- Application Version / Version code and Collection Status / Complete / Source are excluded only from the technical Compare universe.
- ABI, device, Android, driver, OpenGL ES, EGL, limits, runtime enumerations, precision, EGL Configs, diagnostics and Display/HDR remain technical.
- Summary metrics reflect the active filtered universe.
- Stored payloads and report semantics are unchanged.
