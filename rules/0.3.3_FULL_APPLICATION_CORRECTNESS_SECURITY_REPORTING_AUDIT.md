# OpenGLESScope 0.3.3 Full Application Audit

Audit date: 2026-08-23

## Baselines

- Khronos OpenGL ES 3.2 and GLSL ES 3.20 current registry baseline.
- EGL 1.5 implementation/configuration baseline.
- Android API 37 Display/HDR semantics.
- OpenGLESScope Database 0.2.5 producer compatibility reference.

## Corrections from 0.3.2

1. Format enumeration diagnostics were made query-granular: count and value-array operations are now represented separately while retaining legacy aggregate diagnostics for compatibility.
2. OpenGL ES 3.x extension enumeration now records `GL_NUM_EXTENSIONS` separately.
3. Core-version provenance is now explicit in UI, TXT and HTML: direct GL major/minor query versus GL_VERSION parsing fallback.
4. Direct-update opt-out now cancels active HTTP calls and coroutines and prevents installer continuation after opt-out.
5. Invalid downloaded APK targets are deleted after archive/package/signature/version validation failure.
6. APK signing validation is directional on Android 9+: the installed current signer must occur in the candidate signing lineage, preventing an ancestor-only signature from passing merely through set intersection.
7. Database compatibility documentation was updated to Database 0.2.5.

## Reporting coverage

The same collected technical datasets remain available to the in-app destinations, TXT export, self-contained HTML export and schema-v2/technicalReport-v1 Database submission: runtime identity, limits, GL extensions, EGL display/client extensions, compressed formats, shader/program binary formats, shader precision, diagnostics, EGL Configs and Display/HDR evidence.

## Resource and lifecycle review

The native probe clears the current EGL binding and destroys the surface/context before terminating the display. The bound single-worker probe service shuts its executor down on destruction. Probe output remains bounded to 8 MiB and the client timeout remains 20 seconds. No persistent source-level native or Android listener leak was identified in the reviewed lifecycle paths. Dynamic heap profiling/on-device LeakCanary or sanitizer execution is outside this static source audit.

## Security review

Database submission remains fixed-host HTTPS, explicit and bounded. HTML remains self-contained with restrictive CSP/referrer policy and escaped dynamic report values. The updater restricts release assets to the official repository path, validates package identity/signing/version metadata and now provides immediate cancellation on user opt-out plus invalid-target cleanup.
