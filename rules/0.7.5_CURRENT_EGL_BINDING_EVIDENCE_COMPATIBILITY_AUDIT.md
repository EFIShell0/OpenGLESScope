# OpenGLESScope Database 0.7.5 current EGL binding evidence compatibility audit

## Trigger
OpenGLESScope 0.7.0+ treats the EGL runtime binding snapshot as evidence. The application can preserve a complete report when an individual current-context/display/draw/read binding check is false, and its Analysis quality path explicitly consumes those failures. Database 0.7.4 instead rejected any schema-2 report unless all four booleans were true.

## Correction
The Worker no longer equates complete evidence with successful evidence. A false current-binding boolean is accepted only when the `EGL current bindings` query diagnostic is `Unavailable`; all-true bindings require `Available`. Canonical TXT binding values must exactly match the structured booleans. Contradictory diagnostic or TXT evidence remains rejected.

## Compatibility
Current producer remains OpenGLESScope 0.7.2 / versionCode 702. Submission schema 2, technicalReport schema 2, normalizer 10, D1 schema and stored report identity are unchanged. No migration or stored-report rewrite is required.
