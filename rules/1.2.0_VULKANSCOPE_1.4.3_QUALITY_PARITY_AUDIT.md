# OpenGLESScope 1.2.0 quality-parity audit

## Immutable predecessor
- Source: `OpenGLESScope-0.7.3(1).zip`
- SHA-256: `9e2beb25415c3be48f3c58b1e4035ce10c8c432b0357bcdfd70b55a90fb129df`
- Reference comparison: VulkanScope 1.4.3 application source and engineering rules.

## Classification
- REGRESSION: Activity recreation on orientation/window-size changes could restart complete GL/EGL collection and reset primary navigation.
- USABILITY: search state was ordinary `remember` state rather than saveable lightweight UI state.
- CORRECTNESS/NETWORK: update and Database paths attempted requests without first requiring Android validated-internet evidence.
- TEST-GAP: OpenGLESScope did not carry the same release-level registry snapshot lock and parity gate used by the mature reference application.
- PACKAGE/HYGIENE: 1.2.0 formalizes the same clean source-package exclusions, including screenshots.

## Repair
- MainActivity now handles orientation, screenSize, smallestScreenSize, screenLayout and keyboardHidden changes without Activity recreation.
- Primary destination and text search/filter state use `rememberSaveable`; report/native state stays live in Activity/process memory rather than Bundle serialization.
- Update checks and complete-report submission require `NET_CAPABILITY_INTERNET` plus `NET_CAPABILITY_VALIDATED`. Offline GL/EGL inspection remains available.
- Bundled `registry/gl.xml` is locked by `registry/gl_registry_manifest.json`; the manifest records SHA-256, byte size and OpenGL ES feature/extension census metadata.
- `PROJECT_RULES.md` was rewritten to the mature engineering/evidence workflow while replacing Vulkan-only semantics with OpenGL ES/EGL/Android Display semantics.
- Reusable local generic action/status vector resources were synchronized without importing Vulkan branding or Vulkan runtime semantics.
- Release identity advanced to 1.2.0 / 1200.

## Deliberately not copied
- Vulkan physical-device structures, pNext chains, Vulkan Video, VkFormat/VkResult tables, Vulkan Profiles and Turnip/AdrenoTools driver switching have no truthful OpenGL ES/EGL equivalent and are not fabricated.
- Vulkan-specific Database schema fields and Vulkan registry data are not transplanted. OpenGLESScope retains its own GL/EGL report schema and query evidence.

## Verification boundary
- Source/regression/registry/package checks are executable in this environment.
- Android Gradle compile/lint/unit and real-device portrait/landscape/TalkBack/TV reproduction are separate evidence classes; they are reported as NOT EXECUTED if the required Android/Gradle toolchain is unavailable.
