# 0.1.5 Database Audit

0.1.5 establishes the hardened database baseline for complete OpenGLESScope 0.1.13 reports. The release adds cache-safe static assets, CSP, bounded report-detail concurrency, deterministic 50-row report pagination, persistent detail categories, exact query-state semantics, complete structured payload coverage, read-time normalization and stricter Worker validation.

The release does not require the application and database version numbers to match.
