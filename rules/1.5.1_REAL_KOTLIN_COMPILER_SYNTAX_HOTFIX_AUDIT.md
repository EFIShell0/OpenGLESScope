# OpenGLESScope 1.5.1 real Kotlin compiler syntax hotfix audit

The supplied 1.5.0 Android release build completed native compilation for arm64-v8a, armeabi-v7a and x86_64 and failed in Kotlin compilation. The root syntax defect was a missing closing interpolation brace in the TXT EGL-config `unavailableAttributes` expression. The parser recovery errors at `reportHtml` and later declarations were secondary.

1.5.1 changes only the release identity and that Kotlin source defect. GL/EGL collection, schema 2/4, registry locks, security and resource behavior remain byte-identical or semantically unchanged. The release gate byte-locks 1.5.0, verifies only the two allow-listed production files changed, runs a dedicated syntax/hotfix verifier and negative mutation, and requires deterministic clean-extract revalidation.
