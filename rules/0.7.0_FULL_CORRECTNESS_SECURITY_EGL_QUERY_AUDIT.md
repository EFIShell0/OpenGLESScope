# OpenGLESScope 0.7.0 full correctness, security, EGL and query audit

## Scope

This release audits build configuration, OpenGL ES query coverage, EGL runtime/config reporting, native crash/memory behavior, export/database propagation, vendor provenance, security boundaries and Analysis performance semantics.

## Query correctness

- Core external comparison reference capability floor remains 145/145.
- 49 additional implementation queries are tracked, including 18 newly added extension-backed values.
- Extension queries execute only with exact runtime extension evidence.
- `GL_NUM_WINDOW_RECTANGLES_EXT` is not treated as a limit because it is mutable state.
- `GL_MAX_SHADER_COMPILER_THREADS_KHR` is not treated as a capability maximum because the KHR parallel-compile value represents requested/current control state.
- Unsupported/unavailable/unknown/not-applicable semantics are not inferred from absence.

## EGL

- EGL vendor, version, initialized version, client APIs, display extensions and client extensions remain independent evidence.
- Current API/context/display/draw/read-surface state, context config/client/render-buffer data and pbuffer attributes are reported separately.
- EGL Config enumeration remains bounded to 4096 and second-stage returned counts are revalidated.
- `EGL_ANDROID_recordable`, `EGL_ANDROID_framebuffer_target` and `EGL_EXT_pixel_format_float` attributes require their exact display-extension prerequisite.
- Failed EGL runtime/config attribute queries retain exact EGL errors.

## Crash, memory and performance hardening

- EGL context/surface/display and thread-local resources use centralized cleanup.
- GL error draining is finite so a defective implementation cannot trap the probe in an endless error loop.
- Driver-controlled GL enumeration counts, extension strings/tokens, EGL Config counts, shader/program info logs and self-test program binaries are bounded.
- Probe execution remains isolated from the UI process, bounded to 20 seconds and an 8 MiB final result.
- Probe result replacement uses API-24-compatible same-directory `android.system.Os.rename` after fsync.

## Reporting and Database

- UI, TXT, HTML and Database carry EGL runtime/config evidence in addition to existing complete report datasets.
- Submission envelope remains schema 2; 0.7.0 current `technicalReport` is schema 2.
- Database submission stays explicit, complete-report-only, 2 MiB bounded and redirect-disabled.
- Vendor icons/labels are presentation only; raw GL_VENDOR/GL_RENDERER remain authoritative.

## Release gates

- `tools/audit_release.py` must pass.
- JSON/XML/Python/package-hygiene checks must pass.
- Source-code comments remain forbidden.
- Full Gradle/Android/NDK compilation may be claimed only when the environment actually completes it.
