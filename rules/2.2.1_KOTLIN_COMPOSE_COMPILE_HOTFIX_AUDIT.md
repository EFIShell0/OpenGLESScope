# OpenGLESScope 2.2.1 Kotlin/Compose compile hotfix audit

Real Android `assembleRelease` evidence for 2.2.0 reached `:app:compileReleaseKotlin` after all three NDK ABI builds passed and exposed six compile-correctness classes: wrong `drawLayer` import package, missing `animateDpAsState`, missing ScrollState scroll-hint overload, missing `ExpressiveToggleRow`, missing `FlowRow`, and missing `ExpressiveMetric`.

2.2.1 fixes those exact classes without changing capability collection/report semantics. Negative mutation coverage must re-introduce each class independently and prove the verifier rejects it.
