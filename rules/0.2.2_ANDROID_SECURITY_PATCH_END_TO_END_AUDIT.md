# OpenGLESScope 0.2.2 Android Security Patch End-to-End Audit

The 0.2.1 application did not collect or submit `Build.VERSION.SECURITY_PATCH`; therefore Database 0.2.1 had no explicit patch evidence to render. VulkanScope 0.33.10 directly reads `Build.VERSION.SECURITY_PATCH`, includes `securityPatch` in structured submissions, and includes the patch in textual report evidence.

0.2.2 closes all four OpenGLESScope paths: UI, TXT, HTML and Database submission. The value is direct Android platform evidence and is not used for graphics-capability inference.
