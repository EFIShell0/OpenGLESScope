- Native GL/EGL collecting/query/report schema and Database compatibility are unchanged. Database 1.0.16 does not authorize producer 2.2.8.
- Source/static gates are NOT a substitute for actual Android `assembleRelease`, `lintRelease`, `testReleaseUnitTest` and device-level visual, ChromeOS/Googlebook OS/TV/TalkBack tests; report unexecuted steps transparently.
