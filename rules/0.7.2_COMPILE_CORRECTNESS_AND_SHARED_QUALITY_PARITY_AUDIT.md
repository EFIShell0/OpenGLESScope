# OpenGLESScope 0.7.2 compile-correctness and shared-quality-parity audit

## Trigger
A real `:app:assembleRelease` reached `:app:compileReleaseKotlin` after all three native ABIs had built successfully, then failed because the Analysis page used the experimental Material 3 Expressive `LoadingIndicator` without the required opt-in.

## Correction
`AnalysisPage` now carries `@OptIn(ExperimentalMaterial3ExpressiveApi::class)`, matching the shared VulkanScope Analysis implementation pattern. The self-test behavior and evidence model are unchanged.

## Release gate
The source verifier requires the Analysis-page opt-in together with the existing pinned Material 3 Expressive dependency. Archive hygiene rules remain mandatory.
