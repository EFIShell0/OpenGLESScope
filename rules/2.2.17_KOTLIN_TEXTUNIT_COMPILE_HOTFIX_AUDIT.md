# OpenGLESScope 2.2.17 Kotlin TextUnit compile hotfix audit

## Trigger
A real Windows `:app:assembleRelease` reached Kotlin compilation and failed in `MainActivity.kt` because `TextUnit` has no supported `minus` operator for `compactLabelFontSize - 0.5.sp`.

## Correction
The intended 0.5 sp visual reduction is retained without `TextUnit` arithmetic: OpenGL ES uses 7.5 sp in landscape and 8.5 sp in portrait when accessibility scaling is not active. Accessibility scale continues to use the shared 10 sp label size.

## Scope
Production changes are restricted to `app/build.gradle.kts` and `MainActivity.kt`. GL/EGL native queries, registry files, report schemas, Database transport, permissions and other UI behavior are unchanged.

## Evidence
`tests/golden/2_2_17_release_regression_contract.json` freezes the exact 2.2.16 predecessor ZIP and 160 production paths. `tools/verify_2_2_17_kotlin_compile_hotfix.py` and `tools/test_2_2_17_negative_mutations.py` enforce the fix and reject recurrence.
