# OpenGLESScope 2.2.5 input/layout/accessibility audit

Evidence classes: VulkanScope 3.0.12 shipped `MainActivity.kt` used as API-neutral code reference; exact 2.2.4 predecessor ZIP used as immutable production source; no device-level perceptual equivalence claimed.

Findings and fixes:
1. **Desktop mouse drag missing**: earlier OpenGLESScope only delivered wheel events to `ScrollableState`. Adopted VulkanScope slop-aware primary-mouse drag with consumed motion after touch-slop threshold, while retaining wheel dispatch and no duplicate consumed events.
2. **TV-only focus**: browse rows previously returned empty modifier on keyboard/desktop. Adopted all-hardware focus and `BringIntoViewRequester`, suppressed focus when a File Manager row/option is disabled or breadcrumb is current.
3. **Landscape File Manager overflow**: old all-vertical controls squeezed listing height on short landscapes. Two-pane control/list structure for >=700 dp wide landscape with independent scroll, narrow/split-window fallback.
4. **System insets**: fullscreen File Manager used only arbitrary outer padding; now accounts for status/nav insets and suppresses unsupported desktop secondary menus in File Manager, matching source conventions.
5. **RTL**: logical breadcrumb arrows, folder chevrons and search feather direction now follow `LocalLayoutDirection`; GL/EGL raw strings remain unaltered.
6. **High DPI/accessibility**: full/compact navigation height adjusts at increased system font scale, header wordmark shrinks to preserve title, options chooser uses two columns when narrow or fontScale>=1.3. Selection transitions animated and mode artwork is decorative when neighboring Text already names the control. File Manager updates announced politely.
7. **Blur**: OpenGLESScope's real 24 dp `GraphicsLayer` / `AndroidRenderEffect.createBlurEffect` / recorded source-layer + `frostedChromeBackdrop` pathway already follows VulkanScope; original OpenGLESScope palette retained to avoid a Vulkan-specific brand transplant.

Do not claim physical keyboard, TalkBack, HDR pixel-perfect, emulator or real TV hardware passes until actual device test. Database 1.0.16 currently rejects unadmitted 2.2.5 producer; no attempt to fake success or spoof version.
