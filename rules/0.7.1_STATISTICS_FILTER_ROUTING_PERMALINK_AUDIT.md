# OpenGLESScope Database 0.7.1 Statistics / filter / routing / permalink audit

## Scope
0.7.1 closes the frontend-quality gap in cohort exploration, statistics, routing, sharing and comparison controls while preserving the OpenGLESScope 0.7.0 producer and Database storage contracts.

## Statistics
Statistics is a first-class navigation destination. It provides local SVG/CSS distributions for submitted GL vendor, GPU renderer, OpenGL ES version, EGL version, driver mode, Android version, application ABI and OpenGLESScope version. Chart interactions apply exact submitted-evidence filters. The page states explicitly that percentages refer only to loaded and filtered submissions and are not market-share estimates.

Extension enumeration ranking uses exact runtime tokens from OpenGL ES, EGL display and EGL client extension datasets. Scope, namespace, minimum loaded-cohort share and token-search controls are available. Extension percentages are overlapping enumeration prevalence, not exclusive shares.

## Filters
Global cohort filtering covers GL vendor, renderer, OpenGL ES version, EGL version, driver mode/version, Android version, device model, application ABI, application version, submission age and exact extension token. Display/HDR additionally exposes resolution, refresh rate, wide-color state, HDR state and exact HDR-type filters. Clear filters resets the global cohort. Display & HDR ignores graphics/driver/extension cohort dimensions that are not direct display evidence and retains Android filtering only.

## Routing and sharing
Statistics uses the canonical `#statistics` main route and accepts the historical `#trends` alias only for navigation compatibility. Report section routes and two-report Compare routes retain validated 64-lowercase-hex report IDs. Report and Compare share controls generate first-party canonical permalinks without changing stored data.

## Compare
Extensions, Limits, Formats and Shader Precision provide view-scoped row searches. Compare retains differences-only, technical-only, common-evidence and cross-producer semantics. Section filtering and field-name search are presentation-only. Missing one-sided evidence remains Unknown / Not reported.

## Compatibility
Database version advances to 0.7.1. Current producer remains OpenGLESScope 0.7.0 / 700. Submission schema 2, current technicalReport schema 2, normalizer 10, D1 schema, canonical report hashes, existing rows and 2 MiB limits remain unchanged. No migration or stored-report rewrite is required.
