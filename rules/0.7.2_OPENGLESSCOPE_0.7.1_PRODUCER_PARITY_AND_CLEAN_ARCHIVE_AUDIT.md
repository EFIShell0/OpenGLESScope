# OpenGLESScope Database 0.7.2 producer-parity and clean-archive audit

## Producer contract
The current accepted producer is OpenGLESScope 0.7.1 / versionCode 701. Its structured application metadata includes installed ABI and Android-supported device ABIs. Those fields are version-gated so historical report payloads keep their original schema.

## Correctness
Structured ABI metadata must agree with canonical report-text metadata. Runtime metadata prefers the structured current-producer fields while retaining historical fallback parsing.

The Worker no longer requires mutable state/control query names that the application intentionally excludes from implementation capability reporting. This keeps Database validation aligned with the application query contract instead of forcing misleading capability evidence.

## Compatibility
The producer floor remains 0.1.17 and the ceiling advances to 0.7.1. OpenGLESScope 0.7.0 remains accepted under its released application object contract. Technical report schema 2 remains required for 0.7.0+.

D1 schema, normalizer 10, canonical report hashing, existing report IDs and stored payloads are unchanged.

## Archive policy
The source archive contains no README.md, root release.md, dedicated packaged app-store metadata directory or forbidden third-party comparison product naming.

## Release gates
Source audit, repository-state check, JavaScript syntax, routing contract, Compare contract, Statistics/filter contract, Worker contract, audit-hygiene regression and a fresh allow-listed Pages artifact audit are mandatory.
