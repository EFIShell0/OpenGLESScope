# OpenGLESScope 0.3.0 Material 3 Expressive full-UI audit

## Scope
Application UI only. Native OpenGL ES/EGL collection, Display/HDR interpretation, report/export, Database submission, update validation, ABI output and Obtainium metadata remain functionally unchanged.

## Applied parity
- Material3 1.5.0-alpha26 `MaterialExpressiveTheme` and expressive motion scheme.
- Material 3 Expressive short portrait navigation while preserving destination order and semantics.
- Expressive app-bar icon-button state/shape treatment with existing Info-left/Settings-right hierarchy.
- Expressive filter and assist chips for existing format, extension and Explore selectors.
- Expressive tonal search fields while preserving the project-required 22 dp search geometry.
- Expressive Direct GitHub updates switch.
- Expressive confirmation/consent dialog shapes and action buttons.
- Expressive update/collection banners and wavy progress indicators plus expressive loading indicator.
- Shared non-brand functional vector artwork aligned with VulkanScope 0.35.0.
- Existing cards, technical information hierarchy, official OpenGL ES/EGL artwork, vendor logos, HDR logos and brand colors preserved.

## Guardrails
- No graphics capability is inferred or renamed.
- No collection/query path is changed.
- No report, export or Database schema field is changed.
- No update provenance or signing validation is weakened.
- No navigation destination is added, removed or reordered.
- TV/landscape focus and bring-into-view behavior remains intact.
- Source-code comments remain forbidden.
