# OpenGLESScope Database 0.2.8 producer contract

Current producer: OpenGLESScope 0.3.4 / versionCode 304. Duplicate query diagnostics remain rejected. 0.3.4 removes the producer regression that caused real 0.3.3 reports to contain duplicate diagnostic names. Health and report-list metadata are aligned to the same current producer.

Released OpenGLESScope 0.3.3 may duplicate four count-query diagnostics because the same runtime count was read for Limits and enumeration. Database 0.2.8 accepts only those four names, only exactly twice, only when status/detail are identical, and only for producer 0.3.3. Conflicting or arbitrary duplicates remain invalid. OpenGLESScope 0.3.4 removes the producer regression and is subject to strict uniqueness.
