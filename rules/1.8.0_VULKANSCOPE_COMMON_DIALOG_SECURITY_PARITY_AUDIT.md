# OpenGLESScope 1.8.0 VulkanScope common dialog/security parity audit

## Release identity
- Release identity is OpenGLESScope 1.8.0 / versionCode 1800.
- Immutable application predecessor is final OpenGLESScope 1.7.0 ZIP SHA-256 `e1aa3ac048dbd67ec2879884c2eafd1487d6729d9470b05a250e1db7850a2828`.
- Shared interaction/methodology reference remains VulkanScope 1.4.3 and the exact packaged `VULKANSCOPE_1.4.3_PROJECT_RULES_REFERENCE.md`.

## Shared UI parity scope
- Common dialogs use the same Material 3 Expressive extra-large surface, semantic title artwork, icon-bearing Cancel/Close/primary actions and responsive key/value geometry as VulkanScope.
- Common action cards use the same contained semantic artwork, 48 dp minimum activation target and animated trailing-action model.
- Application Info exposes the manual Check for updates action beside installed version information; Settings retains only the Direct GitHub Updates preference and does not duplicate the manual action.
- About carries the same Khronos independence disclaimer structure while truthfully describing OpenGL ES/EGL rather than Vulkan®.
- Shared runtime libraries and build toolchain are exposed using the same Info structure, with OpenGLESScope's actual pinned versions. Packaged license text is local/offline.
- Analysis history and watched-evidence destructive actions require the same explicit confirmation boundary instead of deleting directly.
- Vulkan/Turnip/queue-family/WSI/Vulkan Video/pNext/Profile semantics remain not applicable and are not synthesized.

## Shared updater and network behavior
- Update request ownership, in-flight disabled state, result-hide lifetime, validated-network banner generation and cancellation cleanup follow the same race-safe state ownership as VulkanScope.
- OpenGLESScope's stricter updater security remains non-regression: stable releases only, drafts/prereleases rejected, fixed official GitHub origins, automatic redirects disabled, at most three manually validated HTTPS release-asset redirects, 256 MiB package ceiling, optional official SHA-256 validation, mandatory package/signing/versionCode/versionName verification, private cache storage and stale-artifact cleanup.
- Disabling direct updates or destroying the Activity cancels both the active update check and any pending result-hide job. A pending installer handoff is not resumed while direct updates are disabled.

## Database/report behavior
- Database submission remains explicit, complete-report-only, fixed-origin HTTPS and bounded to 2 MiB without truncation.
- Failure presentation now follows the shared VulkanScope bounded-log contract: detailed failure evidence is capped, shown in a dedicated dialog and can be copied explicitly.
- Submission schema remains 2 and technicalReport schema remains 4. No OpenGL ES/EGL evidence semantics are weakened or reinterpreted by this UI/security parity release.
- Companion Database must explicitly accept exact OpenGLESScope 1.8.0 / 1800 while preserving historical producer contracts and rejecting unsupported future producers.

## Verification contract
- Production changes are allow-listed relative to 1.7.0; non-allowlisted production drift is release-blocking.
- Required gates include current-release parity assertions, stable-updater security, compile-regression/accessibility checks, retained spec/registry/query/lifecycle/resource/report gates, targeted negative mutations, strict package hygiene, deterministic reproduction and clean-extract rerun.
- Android assemble/lint/unit tasks are PASS only if actually executed successfully. A missing/unreachable Gradle distribution remains NOT EXECUTED rather than being inferred from static checks.
