# OpenGLESScope 0.3.1 binary and compressed format enumeration audit

- Runtime query paths verified for compressed texture, shader binary and program binary format arrays.
- `GL_COMPRESSED_TEXTURE_FORMATS` data remains the sole source for compressed formats.
- `GL_SHADER_BINARY_FORMATS` data remains the sole source for shader binary formats.
- `GL_PROGRAM_BINARY_FORMATS` data remains the sole source for program binary formats when applicable.
- Added canonical symbolic decoding for EXT BPTC: 0x8E8C-0x8E8F.
- Added canonical symbolic decoding for EXT RGTC: 0x8DBB-0x8DBE.
- Added canonical symbolic decoding for EXT sRGB S3TC: 0x8C4C-0x8C4F.
- Added canonical symbolic decoding for MESA program binary format 0x875F and DMP program binary formats 0x9251-0x9253.
- Existing ETC/EAC, ASTC 2D/3D, S3TC linear, PVRTC/PVRTC2, ATC, 3DC and paletted format mappings remain intact.
- Unknown values continue to be rendered as raw hexadecimal values.
- UI, TXT, HTML and structured submission paths already consume all three arrays and required no schema change.
