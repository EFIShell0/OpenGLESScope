# OpenGLESScope 2.2.0 capability coverage audit

OpenGLESScope 2.2.0 is a VulkanScope 3.0.12 visual/interaction parity release over 2.1.4. It does not change OpenGL ES/EGL native capability collection, query legality, registry inputs, report schema, or evidence-state semantics.

The locked OpenGL ES 3.2 / GLSL ES 3.20 revision 8 / EGL 1.5 baseline remains authoritative. `gl.xml` and `egl.xml` remain canonical naming/reference inputs; registry presence never proves runtime support. Available, Unavailable, Not applicable and Unknown evidence boundaries remain unchanged.

The release moves EGL™ into the OpenGL® ES navigation hierarchy, aligns shared SCOPE artwork, icons, blur/chrome, evidence actions, dialog treatment and Database presentation with the frozen VulkanScope 3.0.12 API-neutral reference. These presentation changes must not invent, suppress, summarize-away or reclassify collected evidence.

Canonical-name, registry census, GLES query coverage, EGL registry coverage, EGL legality, GL GetPName disposition, schema-5 report-semantic and 2.2.0 UI parity gates remain release-blocking.
